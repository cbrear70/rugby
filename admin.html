Admin

Sign in

Use the admin account you created in Firebase (Authentication → Users). Coaches can't use this page.

New group

Give the join code to the group's coaches. They enter it when they first open the app, or use Group → Add another group.

Groups

Codes are 10 letters or digits; capitals, spaces and dashes are sorted out for you. Random codes leave out I, O, 0 and 1 so they're easy to read out. Changing a join code copies the group's teams and moves to the new code and deletes the old one; coaches are asked for the new code on their next sync and keep everything. Changing a send code moves any waiting moves across; phones pick up the new send code on their next sync.

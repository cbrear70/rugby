Groups

Codes use the letters and digits ABCDEFGHJKLMNPQRSTUVWXYZ23456789 (no I, O, 0 or 1), 10 characters. Changing a join code copies the group's teams and moves to the new code and deletes the old one; coaches are asked for the new code on their next sync and keep everything. Changing a send code moves any waiting moves across; phones pick up the new send code on their next sync.
